## About Me

Hi, I’m Aditya Putra

I’m a full-stack developer who enjoys building clean, efficient, and scalable applications. Most of my work revolves around **Laravel**, **Next.js**, **Inertia.js**, **React**, and **Flutter**, with a strong focus on creating smooth user experiences and maintainable architectures.

I love solving real problems, refactoring messy code into something elegant, and learning new technologies that help me build faster and smarter. I frequently work with database-driven systems, authentication flows, admin dashboards, modern UI frameworks, and mobile apps powered by Firebase.

Outside of coding, I enjoy exploring new tools and experimenting with ways to improve developer workflow and product quality.

If you’re interested in collaborating or discussing ideas, feel free to reach out!
